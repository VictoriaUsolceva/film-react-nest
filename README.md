## Деплой на сервер

### Подготовка переменных окружения
Создайте файл `.env` в корневой директории на основе примера и заполните пароли и данные репозитория:
```bash
cp .env.example .env
```

### Выпуск SSL-сертификата (HTTPS)
Перед запуском основного проекта выпустите SSL-сертификат (убедитесь, что порт `80` свободен):
```bash
docker compose run --rm certbot certonly --standalone -d ВАШ_ДОМЕН
```
Сертификаты сохранятся в локальную директорию `./certbot_data` и автоматически примонтируются в контейнер Nginx.

### Развертывание
Для развертывания на удаленном сервере перенесите туда файлы `docker-compose.yml` и `.env`.

Скачайте актуальные образы и запустите контейнеры в фоновом режиме:
```bash
docker compose pull
docker compose up -d
```

### Заполнение базы данных
Для первичного наполнения базы данных тестовыми данными доступны файлы в директории `backend/test`.

### Безопасность и доступ к сервисам
Из соображений безопасности внешние порты базы данных и панели управления закрыты от публичного доступа из интернета:
* Наружу открыты только порты Nginx (`80` и `443`).
* PostgreSQL и pgAdmin привязаны исключительно к локальному интерфейсу сервера (`127.0.0.1:${PGADMIN_PORT}:80`).

Для доступа к pgAdmin с вашего компьютера используйте SSH-туннель:
```bash
ssh -L 8080:127.0.0.1:8080 user@IP_СЕРВЕРА
```
